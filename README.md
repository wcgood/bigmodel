基于4卡atlas300i-duo的大模型管理平台，自研int4算子，forward解包，图模式。

  # bigmodel —— 面向昇腾 310P 的本地大模型量化与推理科研平台

  在 Atlas 300I Duo（8×Ascend 310P3）上构建的大模型**量化研究 + 引擎优化 + 一体化管理台**
  平台：自研权重转换与量化工具链（W8A8 / W4 / int4-GS64 / FP4→int4），对 vllm-ascend
  推理引擎做深度移植与性能优化（NPU 图模式、MLA KV 吸收、专家缓存与流式解包），
  并配有一套中文 Web 管理台（版本起停 / 实时监控 / 流式对话 / 量化向导 / 评测 / 日志）。

  目标：**在国产推理卡上，把大 MoE 模型以"精度优先"的方式跑起来、跑快，且每一步可复现、可对拍。**

  ## 项目定位与设计原则

  本项目是**科研课题**，第一性原则是数据转换的准确性与可验证性：

  1. **代码与模型分离**：平台代码与模型权重/转换产物分目录管理。
  2. **精度优先**：一切量化与性能改动，先在离线对拍（bitwise / 余弦门禁）通过后，才进入工程代码。
  3. **逐项 opt-in + ablation**：任何优化默认不改变模型精度与路由语义，加速策略逐项开关、逐项对照。
  4. **可复现**：版本档携带"身份段"（镜像 + 量化档 + 参数 + 采样口径），对比实验可复现到档位。
  5. **坑必记录**：所有踩坑进《坑与最佳实践》，方案与实测数据进 docs/。

  ## 核心能力

  ### 1）模型转换与量化工具链
  - **通用权重 → 310P W8A8 转换**：五步向导（结构解析 → 层选择 → 参数 → 执行 → 登记），
    内置自动回归调优（回退阶梯 + C-Eval 达标早停）。
  - **自研 Data-Free W8A8**：纯 numpy、分卷并行、fail-closed 键分类，带黄金对拍门禁。
  - **W4 / int4-GS64 容器**：自研打包 / 解包 / 校验工具链，配套 Ascend C 与 AICPU 解包算子。
  - **FP4 源量化**：DeepSeek-V4.1-Flash 全量 47,232 个专家矩阵完成 int4 转换，全量校验通过。

  ### 2）vllm-ascend 引擎移植与优化
  - **NPU 图模式**：GLM-5.3-Flash 图档实测 ITL 98.5 ms / 10.3 tok/s（eager 形态显著提速）。
  - **MLA KV 吸收**：KV 缓存池存 latent 表示，88 → 11 KB/token/芯，128K 上下文档实测可行。
  - **W4F 专家流式 + 弹性 LRU 缓存**：int4 精度优先档 1.59–1.66 tok/s；显存动态回收。
  - **批量解包 / AICPU 算子链 / 冷热分离** 等一批经消融验证的优化项。

  ### 3）一体化 Web 管理台
  - 版本起停 / 切换 / 参数档管理（每档带完整"身份段"，对比可复现）
  - 加速卡实时监控 + 三档固化基准压测
  - 流式对话：思考开关、多模态图片、工具调用（OpenAI 与 Anthropic 双协议 API）
  - 量化五步向导、C-Eval / QA50 固定口径评测、日志中心

  ### 4）评测与对拍体系
  - 固定口径评测（seed / 温度 / 题数固化）+ 多版本横评
  - 逐请求指标（TTFT / ITL / 分段 tok/s / 结束原因）+ 服务端指标差值 + 硬件窗口
  - 每步优化均有执行记录与离线对拍报告（见 `docs/`）
